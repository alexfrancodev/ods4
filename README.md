# Kanela ODS 2.0 — Nota 02

Versão final baseada no projeto da Nota 01. A aplicação usa React via CDN, componentes funcionais, estado com hooks, eventos, navegação SPA por hash, Fetch API e JSON.

## Como executar
Abra `index.html` em um navegador com internet. Os scripts React/Babel são carregados pelo CDN unpkg.

## API
IBGE Localidades API — consulta do município de Fernando Falcão/MA:
https://servicodados.ibge.gov.br/api/v1/localidades/municipios?nome=Fernando%20Falcao

## Funcionalidades
- Navegação SPA sem recarregar a página
- Componentes React
- useState/useEffect
- Busca e filtro em tempo real
- Eventos de clique e alteração de campos
- Fetch API e tratamento de JSON
- Estados de carregamento e erro
- Layout responsivo
- Conteúdo relacionado aos ODS e ao povo Kanela
